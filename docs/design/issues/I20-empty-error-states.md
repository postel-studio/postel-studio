# I20 · 空态与错误态全面走查

- **里程碑**：M3　**预计**：3h　**依赖**：I13　**优先级**：P2

## 背景

仿制区必须保留**真实空态文案**（UI 规格 §3）。空态若做成空白，会被误认为页面坏了。

## 验收标准

1. 每个面板都有明确空态文案（Code 无分支 / 收件箱无候选 / 项目无关联 / 审计无记录）。
2. 每个错误码都有用户可读文案，且不泄露内部细节（路径、堆栈）。
3. 网络断开时 UI 显示「内核不可达」并提供重连，不是白屏。
4. 权限不足的操作给出原因，不是静默禁用。
5. 所有空态/错误态在浅色与暗色下均可读。

## 涉及文件

- `src/postel_studio/web/assets.py`
- `src/postel_studio/api/errors.py`（新建：错误码 → 文案映射）
- `tests/test_states.py`（新建）

## 测试要求

- 断言每个错误码在映射表中都有条目（枚举全量遍历）。
- 断言文案不含绝对路径与堆栈关键字。
- 空态 DOM 断言。

## 禁止事项

- 不得用空白代替空态。
- 不得把堆栈或绝对路径显示给用户。
- 不得在错误里泄露凭据片段。

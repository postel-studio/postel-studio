# I06 · M1 验收脚本：一条命令验证端到端

- **里程碑**：M1　**预计**：2h　**依赖**：I03, I04　**优先级**：P0

## 背景

「能独立验收」是拆解原则之一。M1 需要一条命令证明：启动 → 绑定 → 分支 → diff → charter，全部在真实仓库上跑通。

## 验收标准

1. `uv run python scripts/accept_m1.py <repo-path>` 一条命令完成全流程并打印结果表。
2. 任一步失败，脚本**非零退出**并指出失败步。
3. 脚本使用临时 `POSTEL_HOME`，不污染真实 `~/.postel`。
4. 脚本结束后清理临时目录与进程（无残留）。
5. 在 CI（或本地一条命令）可重复运行，结果稳定。

## 涉及文件

- `scripts/accept_m1.py`（新建）
- `tests/test_acceptance_m1.py`（新建，把脚本当集成测试调用）

## 测试要求

- 脚本本身必须有测试：用真实临时 git 仓库，断言退出码 0 且输出含各步骤结果。
- 失败路径测试：传入非 git 目录，断言非零退出并指出 `NOT_A_REPO`。

## 禁止事项

- 不得在脚本里使用真实 `~/.postel`。
- 不得跳过任何一步（不允许「先注释掉 diff 那步」）。
- 不得把验收脚本写成只打印「通过」而不实际校验。

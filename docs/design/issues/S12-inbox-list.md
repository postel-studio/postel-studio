# S12 · 收件箱列表（空态、多条、状态标签）

- **里程碑** M2 · **预计** 3h · **依赖** S3 · **优先级** P1
- **用户路径**：点「变更收件箱」→ 看到所有候选（或空态）→ 按状态筛选

## 背景

S11 只有详情。人要"扫一眼有哪些待审"，需要列表。空态必须真实，否则会被误认为页面坏了。

## 验收标准

1. 列表显示每条候选的标题、Bot 名、状态标签、`+/−`、相对时间。
2. 0 条时显示「暂无待审变更」，不是空白。
3. 按状态筛选（仅本地/已推远端/PR 待审）可用。
4. 多条候选按时间倒序排列。
5. 点击某条进入详情（复用 S11）。

## 涉及文件

- `src/postel_studio/web/assets.py`（收件箱列表面板）
- `src/postel_studio/api/app.py`（`candidate.list` 支持 `reviewState` 过滤）
- `tests/test_inbox_list.py`（新建）

## 测试要求

- 0/1/多 三种数据量的渲染断言。
- 筛选：不同状态下返回条数正确。
- 空态文案断言（DOM 文本）。

## 禁止事项

- 不得用空白代替空态。
- 不得把收件箱文案写成「Pull requests」（会被误解为 GitHub 的 PR）。
- 不得让列表分页复杂化（单机数据量小，一次全取）。

Postel Studio

A repository-first Agent workbench.

Postel Studio 是仓库常驻 Bot 的控制面。人派活、看 diff、做验收；Bot 住在仓库里，从仓库事件流认领工作，产出分支、检查与拉取请求 —— 而不是聊天回复。

  • 仓库是第一视图，不是编辑器的侧边栏。
  • Bot 是仓库的一等公民：身份、记忆、独立 worktree、工作日志。
  • Agent 可插拔：产品是适配器层，不是又一个 Agent 内核。
  • 本地执行优先，远程沙箱可选；Git 平台无关。
Status: early skeleton (v0.1). CLI entry point only; no product features yet.

Install

pip install postel-studio

Development

uv sync                 # create .venv, install (editable)
uv run postel-studio    # run the CLI entry point
uv build                # build sdist + wheel into dist/
